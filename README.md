## 🚀 FEATURED PROJECTS

### 1. SSC Tutor AI
> A specialized AI-driven educational platform engineered to generate personalized mock preparation paths and micro-assessments for Secondary School Certificate candidates.

*   **Key Features:** Contextual prompting architecture, automated structural analytics, localized syllabus matching, performance benchmarking.
*   **Tech Stack:** `Next.js App Router`, `TypeScript`, `Gemini API`, `Tailwind CSS`, `MongoDB`.
*   [🌐 Live Demo](https://ssc-tutor-ai.vercel.app) • [💻 GitHub Repository](https://github.com/monir-codes/SSC-Tutor-AI)

### 2. EduFlex
> A comprehensive, modern Learning Management System (LMS) optimized for seamless, interactive delivery of professional development curricula.

*   **Key Features:** Fluid progress tracking pipelines, dynamic role-based nested dashboards, optimized assets lazy-loading, intuitive streaming interfaces.
*   **Tech Stack:** `React`, `Node.js`, `Express.js`, `MongoDB`, `TanStack Query`, `shadcn/ui`.
*   [🌐 Live Demo](https://eduflex-next.vercel.app) • [💻 GitHub Repository](https://github.com/monir-codes/EduFlex)

### 3. EcoTrack
> A production-ready ecosystem and interactive community application targeted at driving, measuring, and reporting sustainable everyday actions.

*   **Key Features:** Global gamified leaderboards, scalable user tracking workflows, complex relational activity records, high-fidelity responsive UI components.
*   **Tech Stack:** `React`, `Firebase Authentication`, `Tailwind CSS`, `DaisyUI`, `Express.js`, `Mongoose`.
*   [🌐 Live Demo](https://ecotrack-monir.vercel.app) • [💻 GitHub Repository](https://github.com/monir-codes/EcoTrack---Sustainable-Living-Community)
